# Новости zStore (HTML)

Весь раздел новостей правится здесь. В приложении остаётся только оболочка (WebView, назад, pull-to-refresh).

## Файлы

| Файл | Назначение |
|------|------------|
| `d.html` | Лента: заголовок, подзаголовок, карточки |
| `n/01.html`, `n/02.html`… | Страницы новостей |
| `covers/01.png`, `02.png`… | Обложки (~1170×450) |
| `news.css` | Дизайн (карточки, шрифты, отступы) |
| `c.json` | Сигнал приложению обновить новости (`revision`) |

## Как добавить новость

1. Положи обложку `covers/03.png`
2. Скопируй `n/02.html` → `n/03.html`, поменяй текст и `src="../covers/03.png"`
3. В `d.html` добавь карточку (скопируй блок `a.card`)
4. Увеличь `revision` в `c.json` на 1

«Добро пожаловать» (`n/01`) держи **первой** карточкой в `d.html`.
