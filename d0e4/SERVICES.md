# Сервисы (HTML)

Весь UI раздела **Сервисы** живёт здесь. Приложение только показывает WebView и кэширует страницы, пока не сменится commit SHA в GitHub.

## Файлы

| Файл | Назначение |
|------|------------|
| `a.json` | Манифест: `revision`, `badge`, `site`, опционально `services` |
| `s.html` | Лента: заголовок, поиск, фильтры, карточки |
| `services.css` | Дизайн |
| `s/{id}.html` | Страница сервиса |
| `icons/` | Иконки (`icons/VPNIcon.png`) |

## Как добавить сервис

1. Положи иконку в `icons/Name.png`.
2. Добавь карточку `<a class="row" …>` в `s.html` (`href="s/{id}.html"`, `data-category`, `data-search`).
3. Создай `s/{id}.html` по образцу `vaynah-vpn.html`.
4. Подними `revision` (и при необходимости `badge`) в `a.json`.
5. Закоммить в `ZAUr0/r4n7-files` — клиенты подтянут после смены SHA.

## Важно

- Отступы должны совпадать с вкладками (заголовок 20pt, список 16pt, радиус 24).
- Внешние ссылки (`https://t.me/…`) открываются системой; внутренние `s/*.html` — в приложении.
- Не меняй `site` в `a.json` без нужды (`"site": "s.html"`).
