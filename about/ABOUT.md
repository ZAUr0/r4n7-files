# О приложении (HTML)

Весь экран «О приложении» правится здесь. В приложении — только оболочка (WebView, назад).

## Файлы

| Файл | Назначение |
|------|------------|
| `about/index.html` | Контент страницы |
| `about/about.css` | Дизайн |
| `about/zaur.jpg` | Фото разработчика |
